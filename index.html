What is Monte Carlo Simulation?

Monte Carlo simulation solves problems by using repeated random sampling. Instead of solving a complex equation directly, we run many random experiments and use the overall pattern to estimate the answer.

In this project, random points are thrown inside a square. Some points land inside a circle drawn inside that square. The ratio helps estimate π.

Green dots: inside circle. Red dots: outside circle.

How This Project Estimates π

π ≈ 4 × (points inside circle / total points)

  1. Generate a random point (x, y) between -1 and 1.
  2. Test whether x² + y² ≤ 1 (inside unit circle).
  3. Repeat for many tosses.
  4. Use the fraction of inside points to estimate π.
Unit circle area = π Square area = 4 So fraction ≈ π/4

Sequential vs Parallel Programming

Approach How It Works Typical Outcome
Sequential One thread performs all tosses one by one. Simple but slower for very large toss counts.
Parallel (OpenMP) Multiple threads split tosses and combine totals. Often faster, especially on multi-core CPUs.

For Monte Carlo tosses, each toss is independent. That makes this problem a strong candidate for parallel work sharing.

How OpenMP Works Here

Plain English: OpenMP allows the program to split tosses across CPU threads so many tosses are processed at the same time.

  • Threads: A team of workers is created.
  • Work sharing: Toss loop iterations are divided across workers.
  • Reduction: Each worker keeps a local count, then counts are safely summed.

Technical note: The parallel function uses #pragma omp parallel and #pragma omp for reduction(+: no_in_circle) to avoid race conditions while aggregating results.

Code Walkthrough

Random Number Generation

getRand() uses thread-safe rand_r with per-thread seeds to produce values in [-1, 1].

Inside Circle Test

Each toss computes x*x + y*y; values ≤ 1 count as “inside”.

Sequential Function

Calculate_Pi_Sequential loops through all tosses on a single thread.

Parallel Function

Calculate_Pi_Parallel splits tosses across threads and combines results via reduction.

Timing

gettimeofday measures elapsed seconds for sequential and parallel runs.

How to Compile and Run

Use GCC with OpenMP support:

gcc -fopenmp monte_carlo_lab1.c -o monte_carlo
./monte_carlo

Tip: On some systems you may need to install GCC separately if your default compiler does not support OpenMP.

Why Parallel Programming Matters

  • Data analysis pipelines processing millions of records.
  • Scientific simulations in physics, chemistry, and climate modeling.
  • Financial risk modeling using repeated scenario sampling.
  • Image/video processing workloads with per-pixel or per-frame tasks.
